# Logo Files Directory

Please upload the Varnika IT Consulting logo files to this directory:

## Required Files

1. **logo-light.svg** or **logo-light.png**
   - Logo version for use on dark backgrounds
   - Recommended: SVG format (scalable) or PNG at 400px width minimum
   - Should have light/white coloring

2. **logo-dark.svg** or **logo-dark.png**
   - Logo version for use on light backgrounds
   - Recommended: SVG format (scalable) or PNG at 400px width minimum
   - Should have dark coloring (navy or black)

## File Specifications

- **Format:** SVG preferred (scalable without quality loss), or PNG
- **Size:** SVG (any size), PNG minimum 400px width, recommended 800px for retina displays
- **Transparency:** PNG should have transparent background
- **Color:** 
  - Light logo: White or light gold (#F4C430) for dark backgrounds
  - Dark logo: Navy (#003366) or dark version for light backgrounds
